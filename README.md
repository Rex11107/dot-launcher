# Dot Launcher

Launcher Android minimale in stile dot-matrix, ispirato all'estetica Nothing ma scritto da zero (nessun codice, font o marchio di Nothing).

## Funzioni
- Orologio e data a puntini con font 5×7 originale (accento rosso).
- Meteo gratuito da Open-Meteo: posizione automatica o città scelta a mano.
- Icone monocromatiche (usa le icone tematiche di Android 13+ quando l'app le fornisce), oppure bianco e nero o a colori.
- Home con fino a 5 app preferite.
- Cassetto app con ricerca: scorri in su o tocca "APP".
- Widget di sistema: tieni premuto lo sfondo › Aggiungi widget. Tieni premuto un widget per ridimensionarlo, spostarlo o rimuoverlo.
- Scorri in giù sulla home per aprire le notifiche.
- Sfondo nero oppure sfondo di sistema.

## Installazione
1. Apri l'ultima release: https://github.com/Rex11107/dot-launcher/releases/latest
2. Scarica `DotLauncher.apk` e installalo.
3. Impostazioni › App › App predefinite › App iniziale › **Dot Launcher**.
4. Su Honor/Huawei: Impostazioni › Batteria › Avvio app › Dot Launcher › Gestisci manualmente, con tutti gli interruttori attivi.

## Compilazione
Ogni push su `main` compila l'APK con GitHub Actions e pubblica una nuova release.
